### 📐 How I build

- **Claude Code first** — specs live in `CLAUDE.md`, repeatable work becomes skills, MCP connects the tools (Meta, Canva, GHL, WordPress).
- **₹0/month by default** — local LLMs, free tiers, SQLite. Paid services sit behind a flag.
- **Humans approve, machines draft** — nothing sends, spends or posts without a tap.
- **Config over code** — keywords, weights and thresholds live in YAML, not Python.
